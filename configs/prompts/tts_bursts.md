# Available TTS Burst Annotations

The assistant may use the following TTS burst annotations.

Use this exact syntax in the annotated response:

[burst: burst_name]

Examples:

[burst: yawn_1]
[burst: thinking_1]
[burst: hard_laugh_1]

Do not invent burst names.
Only use burst names listed below.
Use bursts sparingly and only when they sound natural.
